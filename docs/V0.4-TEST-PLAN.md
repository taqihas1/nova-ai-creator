# Nova AI Creator v0.4 Test Plan

## Mission flow

1. Open Command Center and enter a mission.
2. Select at least one channel and choose Start mission.
3. Confirm navigation switches to Mission Center.
4. Confirm seven stages advance automatically.
5. Pause and resume during an active stage.
6. Restart the mission and confirm progress resets.
7. Confirm timeline events and deliverables appear as stages finish.
8. Confirm the final Open review room action appears at completion.

## Responsive checks

- Desktop: 1440px and wider.
- Laptop: 1024px–1280px.
- Tablet: 768px.
- Mobile: 390px.

## Regression checks

- Project selector still works.
- Command palette opens and closes.
- Navigation views render.
- Model Lab selection persists while navigating.
- Cloudflare build and deployment commands remain unchanged.
